Reinforcement Learning: ein Modell, vier Haltungen eines Doppelpendels

09/2026

Eine selbst trainierte TQC-Policy schwingt ein Doppelpendel auf einem Wagen in jede seiner vier Haltungen und wechselt auf Wunsch zwischen ihnen. 100 % Erfolg über alle 4×4 Wechsel nach 1,7 Mio. Schritten auf einer Laptop-CPU. Läuft live auf meiner Website.
